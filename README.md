# 小米 12S Ultra 当热点：稳定性 + 天线

## 0. 先搞清楚是哪一段在断

"连了很快就断"有两种，处理方式完全不同：

| 现象 | 断的是哪段 | 主要原因 |
|---|---|---|
| 电脑/设备的 Wi‑Fi 直接掉线、搜不到热点 | 手机 ⇄ 设备 (Wi‑Fi) | 热点自动关闭、省电杀后台、过热 |
| Wi‑Fi 还连着，但网页打不开 | 手机 ⇄ 基站 (蜂窝) | 信号弱、5G/4G 来回切、硬件加速 bug |

跑 `termux/hotspot_watchdog.sh`，看 `~/hotspot.log` 里是 `AP=OFF` 还是 `net=DOWN`，就知道是哪段。

## 1. 手机设置（不需要 root，先做这些）

**热点本身**（设置 → 连接与共享 → 个人热点）
- **"无设备连接时自动关闭" → 关闭 / 从不**（最常见的断线原因）=> DONE
- 加密用 **WPA2‑PSK**，不要 WPA3（很多老设备 WPA3 会频繁掉）
- 频段：设备离得近、要速度 → 5GHz；隔墙、距离远 → **2.4GHz 更稳**
- 关闭"流量上限/热点流量提醒"

**省电 / 后台**
- 关闭省电模式、关闭"超级省电" => DONE: 设置为性能模式
- 设置 → 电池 → 更多设置 → 关闭"睡眠时断开数据"
- 设置 → 应用 → Termux → 省电策略 **无限制**，自启动 **允许**，最近任务里给 Termux **加锁**

**开发者选项**（设置 → 我的设备 → 全部参数 → 连点 OS 版本 7 次）
- **移动数据始终处于活动状态** → 开
- **网络共享硬件加速** → **关**（高通机型上"连着但没网"很多是它导致；关掉后如果速度明显下降再打开试试）
- 关闭 "MIUI/HyperOS 优化" 一般不需要，先别动

**蜂窝网络**
- 信号一般的地方，**锁 4G（首选网络类型 = 4G）往往比 5G 稳**：5G/4G 来回切换就是一次断流，而且 5G 基带更热
- 关闭"双卡网络加速"/"Wi‑Fi 与移动数据双通道加速"

**散热**（12S Ultra 骁龙 8+ 开热点 + 5G 会很热，过热会降速甚至关热点）
- 去掉手机壳，竖着放，背面朝空气；最好**用一个手机散热背夹**（几十块，效果最明显）
- 长期插电：打开 设置 → 电池 → **智能充电保护**，避免满电高温边充边用
- 日志里 `temp` 超过 ~43°C 就会开始降频

## 2. Termux 脚本

```bash
# 把 termux/ 目录拷到手机，在 Termux 里：
pkg install android-tools termux-api   # 同时去应用商店/F-Droid 装 Termux:API app
bash setup.sh                          # 一次性：保持移动数据、关闭 tether offload、加电池白名单
SSID=MyAP PASS=12345678 BAND=2 bash hotspot_watchdog.sh
```

权限三档，脚本会自动选：
1. **root (Magisk)**：热点掉了直接用 `cmd wifi start-softap` 重开，掉网自动开关移动数据
2. **adb（不用 root）**：开发者选项 → 无线调试 → 用配对码配对，然后在 Termux 里
   `adb pair localhost:配对端口 配对码`、`adb connect localhost:端口`。
   能改系统设置、读信号/客户端数；部分 ROM 上 shell 用户无权 `start-softap`，就退回第 3 档的行为
3. **什么都没有**：只做监控 + 持锁防休眠，热点掉了弹通知并打开热点设置页让你点一下

开机自启：装 **Termux:Boot**，把启动命令放进 `~/.termux/boot/hotspot.sh`。

## 3. 更稳的方案：别让手机自己发 Wi‑Fi

手机的 Wi‑Fi 天线小、功率受限、还要同时扛蜂窝和发热。要"最大性能 + 稳"，就让手机只连蜂窝网，Wi‑Fi 交给路由器发。

### 3.1 Type‑C 转网口 + 网线 + 普通路由器（首选，已确认可行）

已确认 12S Ultra 系统里有"**以太网网络共享**"开关，任何普通路由器都能用。

```
[基站] ~~4G/5G~~ [12S Ultra] ─Type‑C转网口─ 网线 ─ [路由器 WAN 口] ~~Wi‑Fi~~ [电脑/设备]
```

**转接头**
- 芯片选 **Realtek RTL8153**（千兆，首选）或 RTL8152（百兆）。AX88179 也基本能用
- 最好买 **"网口 + PD 充电"二合一**的，这样手机可以边共享边充电，长时间运行不掉电。到手后实测一下能不能同时充电和共享

**手机端**
1. 插上转接头和网线
2. 设置 → 连接与共享 → 个人热点 → 打开 **以太网网络共享**
3. 手机自己的 Wi‑Fi 热点关掉（省电、少发热）
4. 第 1 节的设置照样保留：移动数据始终活动、关网络共享硬件加速、信号一般时锁 4G、散热

**路由器端**
- 网线插 **WAN 口**
- 上网方式设成 **自动获取 IP（DHCP / 动态 IP）**，不要用 PPPoE 或静态 IP。手机当上级网关，会给路由器分配地址
- Wi‑Fi 名称、密码、频段都在路由器里设；路由器会自己处理 2.4G/5G 和多设备
- 这样是两层 NAT，日常上网、视频、游戏都没影响（只有需要公网端口映射的场景不行，手机流量本来也没有公网 IP）

**摆放**
- 手机放窗边/高处信号最好的地方，路由器放在要覆盖的房间，中间用网线连，几十米都没问题
- 这样"手机要追信号"和"Wi‑Fi 要覆盖房间"就不冲突了

**排查**
- 路由器 WAN 拿不到 IP：拔插一次网线，或在手机上关开一次"以太网网络共享"；检查是否插在了 LAN 口
- 拿到 IP 但没网：先在手机上直接打开网页确认蜂窝网正常；再试第 1 节"网络共享硬件加速"开/关两种状态
- 隔一段时间断：多半是蜂窝那段，按第 1 节锁 4G、看信号；或手机过热（去壳、散热背夹）
- 注意：`hotspot_watchdog.sh` 目前只检测 Wi‑Fi 热点，用这个方案时**不要运行它**，否则它会以为热点掉了并反复去重开

### 3.2 USB 共享网络 → 旅行路由器（备选）

手机 USB 线插到 GL.iNet / OpenWrt 小路由（需支持 USB tethering），手机开 **USB 网络共享**，由路由器发 Wi‑Fi。
效果和 3.1 类似，还能直接给手机供电，但要求路由器支持 USB 共享，普通家用路由器一般不行。

## 4. 外接天线 / "雷达形铝罐" 到底有没有用

**结论：小米 12S Ultra 没有外接天线接口，"铝罐天线"那种（cantenna）需要把馈线接到网卡天线口才行，手机上用不了。**
唯一可行的是**无源反射板**（抛物面/弧形铝片放在手机后面），但效果有限：

- 对 **Wi‑Fi 那段**：能把信号往一个方向集中，正前方可能 +3~6 dB，**但背后和侧面会变差**。手机里有多根 Wi‑Fi/MIMO 天线分布在不同位置，反射效果不好预测。只有"设备都在同一个方向、比较远"时才值得试
- 对 **蜂窝那段**（更常是真正瓶颈）：金属贴近手机反而可能挡住蜂窝天线（12S Ultra 的天线在边框上），**可能变差**
- 试的话：铝片离手机 3~5 cm，弧面朝向要覆盖的设备，用测速 + 日志里的 `rsrp`/客户端设备的信号前后对比，没有明显提升就别用

**真正有用的"外接天线"方案：**
1. **找信号最好的位置**：窗边、高处，比任何土法天线都有效。看 `rsrp`：> -90 好，-90~-105 一般，< -105 差
2. **4G/5G CPE 路由器 + 外接天线**：把 SIM 卡插到带 SMA 天线口的 CPE（华为/中兴/小米 CPE 或工业 4G 路由），接**定向板状天线/八木天线**对准基站。这是信号差地区的正解，蜂窝那段可以提升 10 dB 以上
3. Wi‑Fi 覆盖不够：用第 3 节接的路由器，选带外置天线的型号，或者再加一个 Mesh 节点

## 排查顺序建议

1. 关"无设备时自动关闭" + WPA2 + 2.4GHz + 关硬件加速 + 锁 4G + 去壳散热
2. 跑 watchdog 看日志，确认是 `AP=OFF` 还是 `net=DOWN`
3. 还不稳，或者想要最大性能 → 改用 3.1：Type‑C 转网口 + 网线 + 路由器（以太网网络共享）
4. 信号本身差（rsrp < -105）→ CPE + 外接定向天线
